# Lessons ledger — each lesson is a check, not a story

Format: **defect → evidence → stage that missed it → check → status**. Stage numbers follow the SOT (1 normalize,
2 story bible, 2.5 anchors/plates/keyframes, 3 compile + preflight, 3.5 animatic, 4 generation, 5 FilmQC,
6–7 assembly, 8 delivery). Status: `check exists` (in code), `partial`, `review` (human check in this skill only),
`open` (backlog item in `CRAFT_GAP_BACKLOG.md` or the handoff), `fixed on sample` (one live sample).

When you find a defect: fix it in the stage that should have caught it, then add a row here. Shared format and
cross-project lessons: skill `film-lessons`. Sources are read-only; quote paths, not content.
